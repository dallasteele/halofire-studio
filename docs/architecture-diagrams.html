1 Meta Process — How We Build Software for Any Business

The Business Automator plugin follows a 6-step consulting process (inspired by Luke Pierce). This is the master workflow for creating custom AI-automated software for any small business. 

flowchart TD
    START([🔥 New Client Engagement]) --> D

    D[/"📋 STEP 1: DISCOVERY (20 min)\n─────────────────────\n• Client interview (org chart, tools, pain points)\n• Scrapling auto-researches industry\n• Process inventory ranked by time cost\n• Everything saved to Obsidian Brain"/]
    D --> M

    M --> A

6 Learn & Replace — How AI Progressively Automates Roles

The core innovation: the system watches how humans use it, detects patterns, proposes automation, and tracks an Automation Score per role. Like Dentrix — but one that actually learns. 

flowchart TB
    USER["👤 User Does Task Manually"] --> LOG

    LOG["📝 Behavior Logger\n──────\nWho: Estimator (Jake)\nWhat: Looked up pipe price\nHow: Manual search\nTime: 45 seconds\nScreen: Bids/Edit\nFrequency: 12x this week"]

    LOG --> PATTERN

    PATTERN["🔍 Pattern Detector (Qwen, weekly)\n──────\n'Estimator does manual price lookup\n12x/week × 45sec = 9 min/week\n= 7.8 hours/year\nAUTOMATABLE: HIGH'"]

    PATTERN --> PROPOSE

    PROPOSE["💡 Guide Surfaces Suggestion\n──────\n'Hey Jake — I noticed you manually\nlook up pipe prices for every bid.\nI can auto-fill from ARGCO catalog.\nWant me to start doing that?'"]

    PROPOSE --> APPROVED["✅ Approved\n──────\nAutomation Score +5%\nTask now auto-handled\nBrain stores pattern"]

    PROPOSE --> DENIED["❌ Denied\n──────\nBrain stores:\n'User prefers manual\nfor price lookups'\nNever suggests again"]

    APPROVED --> SCORE

    SCORE["📊 Role Automation Score\n──────\nEstimator: 45% → 50%\nPM: 30%\nAdmin: 72%\nForeman: 20%"]

    SCORE --> THRESHOLD{"Score > 75%?"}

    THRESHOLD -->|"Yes"| ALERT["🔔 Owner Alert\n──────\n'Admin role is 75% automated.\nConsider: reduce to part-time\nor reassign to higher-value work'"]

    THRESHOLD -->|"No"| CONTINUE["Continue Learning\n──────\nMore patterns detected\nover time → score climbs"]

    CONTINUE --> USER
