## Source docs (JS-rendered — scrape with Scrapling, NOT plain fetch)
- Main menus: https://autosprink.com/help/1?v=latest
- Toolbars:  https://autosprink.com/help/45?v=latest
Plain HTTP fetch returns only the page title (SPA). Codex: use Scrapling
(headless browser) to extract every menu → submenu item → description, and every
toolbar → button → description, into:
  docs/research/autosprink-menus.json   {menu, items:[{name, desc, shortcut?}]}
  docs/research/autosprink-toolbars.json {toolbar, buttons:[{name, desc}]}
Each entry needs-verification until a human confirms against the real app.

## Top-level menu bar (confirmed from the official docs TOC, user screenshot)
File · Edit · Select · Snaps · Tools · Actions · Commands · Auto Draw ·

- Menus open on click OR Alt+<underlined letter> (e.g. Alt+F = File). Esc closes.

## UI requirements (user, exact)
- Real DROPDOWN menus under a menu bar like all professional software — NOT a
  flat row of buttons. Apple-glass black styling, Halo Fire branding only.
- EXPORT (DXF/STEP/IFC/STL) lives under File (File → Export →…), not as loose
  top-bar buttons (current toolbar row was a first pass — fold into the menus).
- Keyboard: Alt-mnemonics + Esc, AutoSprink-style.
- The current view tools (3D/Top/Fit/Select/True scale) become View-menu items
  AND optionally a compact toolbar row beneath the menu bar (AutoSprink has both
  menus and toolbars).
- Every Studio capability we already have maps INTO this menu structure:
  Generate Layout → Actions/Auto Draw; hazard/markup → Design Basis under
  Settings or Wizards; LAYERS → View → Layers; floor-plan underlay toggle →
  View; part inspector → Window or Select context.

## Mapping skeleton (fill from scrape; build in this order)
1. File: New/Open/Save project, Import (PDF/DXF/SVG), Export (DXF/STEP/IFC/STL),
   Print/submittal, Recent, Exit→Workbench.
2. View: 3D/Top/Iso, Fit, True scale, Layers (incl. Floor plan underlay,
   ceiling grid, hangers), Inspector panel.
3. Select: select mode, by-type filters, clear selection.
4. Tools/Actions/Auto Draw: Generate Layout, manual pipe (T1), heads, regen.
5. Hydraulics: run calc, supply curve, results panel.
6. Parts Database: open catalog (registry), part search, cut-sheet links.
7. Listing: BOM/takeoff, coupling counts, export bid.
8. Remaining menus (Snaps, Commands, Roof Planes, Wizards, Finish, Alerts,
   AutoPREP, Settings, Window, Help): create stubbed structure from the scrape;
   wire as features land. Stubs are visible + grayed with a needs-verification
   tooltip — flag-don't-gate.
