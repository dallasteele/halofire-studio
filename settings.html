Attach catalog part (admin)

Attach a real catalog model to one component so the demo renders the ACTUAL part instead of the generated shape. Web-mesh formats (stl/glb/gltf/obj) render the actual component; other formats (step/stp/dwg/dxf/pdf) are recorded as evidence only and are NOT rendered. Manufacturer-exact applies per-part and ONLY when BOTH manufacturer and license are attested. This affects one component at a time — it does NOT clear the AUTOSPRINK parity gate, which stays blocked (no parity/AHJ/PE/permit/fabrication claim).
